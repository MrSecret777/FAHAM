# FAHAM Vercel Settings

The current GitHub repository is a static HTML/CSS/JavaScript frontend, not a Next.js app.

Use these Vercel settings:

- Root Directory: `.`
- Framework Preset: `Other`
- Build Command: leave empty
- Output Directory: `.`
- Install Command: leave empty

Do not use the Next.js preset unless the Next.js project files are pushed to the repository root, including `package.json`, `app/`, `next.config.ts`, `tsconfig.json`, and Tailwind/PostCSS config.
